**Beta Day Shop — Full-stack e-commerce portfolio**

Java 25 · Spring Boot · React · TypeScript · PostgreSQL · Kafka · Docker · GitHub Actions

- Built a customer storefront and staff/admin portals covering catalogue, stock, checkout, simulated payments, delivery tracking, inspected returns and refund approval.
- Implemented JWT authorization and resource ownership across a gateway and five business services, with durable user-scoped idempotency and Kafka outbox/event deduplication for recovery.
- Added automated service, frontend and PostgreSQL/Kafka integration checks, plus real-stack browser coverage for purchase, delivery, return/refund and access-control workflows.
